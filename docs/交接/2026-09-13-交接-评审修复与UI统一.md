## 3. 四批变更与关键决策

**A. 评审 24 条修复**：逐条权威记录在 `docs/审查/2026-09-13-场景档案v2双轴评审.md` 第五节。要点：`computeMcpPlan` 改产**补集**（勾=启用，未勾服务器→`['*']` 整台停）、空段可持久化、进入模式先落盘再应用、失败如实报"回滚未完成"、记忆收窄 `active=[S]`、仅记忆场景结构化拒绝、`defineTool` 统一注册、读 `result.diagnostic`。
**C6（实测抓出）**：`readDisabledTools` 用 `/^[A-Za-z0-9_-]{1,128}$/` 过滤，`'*'` 被静默丢弃 → 整台停用四条链路（guard/restrict/快照/`allToolsDisabled`）空转。已修（`src/index.ts` 放行 `'*'`）。

**B. 导入**：`subagent-import`（`.md` 一文件一人设、`.zip` 解包、同名跳过并报告）、`rules-import`（`.zip` 带目录→目录名当场景，裸 `.md` 落所选场景，留空=全局）；全局记忆 `resolveActiveScenes` 纳入根层 `''`；`rules-create` 允许空场景。

**C. UI 统一 + 档案编辑器重做**：三段改统一**段卡片** `.dsm-seg`（标题栏+固定高度滚动体 216px+脚注）；弹窗 `.dsm-modal-archive` 固定高度 → 加/删段、进出"选工具"都不改尺寸（实测恒 620px）；"选工具"改为**段内切换**；每段新增 全选/清空；顶部摘要+语义说明；空段脚注三处接上。`Notice` 统一通知（成功=浮层，警告/错误=文档流横幅，七页全走）；内联样式去 4/5 处；页头同构 + 场景页补三格统计；侧栏 `TOOLS`→`工具`；技能页标题"技能"；七页描述统一单句（中英）。

**D. 技能同名自选**：同名默认按来源 `rank`（project 100/200 < dsh 400 < agents 450 < codex 520 < claude 530 < custom 600）取最高者生效，其余"被覆盖"且不可启停。新增**显式首选** `preferredSkills: {声明名→来源key}`（缺键=回自动）。`groupLoadableSkillsByName(items, preferred)`（已 export）首选命中排最前、其余按 rank、键失效自然退化；`markWinners` 只有"首选命中且确实赢了"才标 `view.preferred`。新 op `skill-prefer/skill-unprefer`（进 writeOps 门禁），只写本地策略、不动源文件。前端：被覆盖行给提示+「启用这个」，赢家给「同名首选」标记+「取消首选」。
校验取舍：`validPreferredSkillName` **故意宽松**（只挡路径分隔符/超长），避免一个脏声明名把整份状态文件判非法而 fail-closed；非法条目在 `normalizeManagerState` 逐条丢弃。

**决策记录**：① 退出模式按快照**原文**整体回写 MCP 停用表——旧"快照后新增键保持现状"会泄漏模式自己写入的键（`server:['*']` 退出后残留），`computeRestorePlan` 已删；② spawn provider **不写 yml 行**（有意偏离设计 §3.2，用户批准）：insert 行启动期解析，缺包宿主整树起不来，且与运行时兜底有双挂载窗口，落地为 `ctx.subagents.list()` 探测 → 缺失才 `apply()` → 失败原因原样抛给模型；③ 弹窗固定高度：用户明确抱怨"排版变来变去"，自适应高度加/删段必跳；④ MCP 页仍硬编码中文（未 i18n），历史遗留，本轮只统一结构与文案风格。
