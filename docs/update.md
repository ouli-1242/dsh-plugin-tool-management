# 版本更新概要

每个版本**大致改了什么**——想知道「升上去会变什么」看这里就够了。
逐条细节、边界与已知限制见 [Changelog](./Changelog.md)；功能说明见 [README](../README.md) / [README_EN](../README_EN.md)。

> 版本号 = npm 上实际发布的发布号（`npm view dsh-plugin-tool-management versions`）。
> 日期 = npm 发布时刻（**UTC**）；本地时间（UTC+8）比它晚 8 小时。
> 开发期的内部编号 `v0.3` / `v0.4` 没有单独发布，内容随 v0.5.0 一起出去。

## v0.6.0（2026-09-14）

- **新增「工具 → 兼容」页**（第 8 个页签）：一屏看清宿主版本与要求范围、插件适配版本、能力可用数（如 15/15）、每个宿主动作走**原生入口 / 插件适配层 / 不可用**、以及哪些能力已降级与原因。只读体检，不改任何数据。
- **兼容判定换底座**：不再拿**源码文本**比对官方实现（上游改一行注释就整体拒绝服务），改为「模块实体是否同一份 + 能力探测」。缺能力时按能力路由（原生 → 适配层 → 拒绝），拒绝信息写明**缺什么、后果、怎么修**，并且永远发生在**任何写入之前**。配套新增 `node scripts/doctor.mjs`（只读体检）与 `node scripts/host-deps.mjs`（把插件依赖 junction 到宿主安装，`--fix` / `--restore`）。
- **归档会话不再丢工作区归属**：工作区登记被删除后，分组按会话目录自动重建（标「工作区已移除」/「未登记的工作区」），目录仍在时可一键**重新登记**；恢复归档会话时会顺带把它挂回工作区记账（此前恢复出来只会掉进「未分组」）。归档账本 / 保留期 / 登记快照搬出插件目录，避免 `dsh plugin update` 覆盖整个目录时丢账本。
- **技能来源权限语义修正**：默认来源（`DSH 技能` / `导入技能`）**必须读取**——不可移除、不可停用，但**里面的技能可以删**（进回收站、可从回收站原样放回）；外部 Agent 目录与自定义目录可以停用 / 移除（不再读取），但里面的技能**只读、不能删**。顺带修好「导入技能里删掉的技能无法从回收站恢复」。
- **切换场景 = 直接换 AGENTS.md**：启用/切换场景、改绑提示词、编辑"正在生效的那份预设"的正文，都会把那份预设**真写进 `~/.dsh/AGENTS.md`**（覆盖前多代备份，最近 5 代保留在 `agents-md/__last-applied__/`）；**关掉场景时按原文恢复进场景之前的基线**（手写内容也能原样回来）。除保留场景「全局」外**同时只能启用一个场景**（启用后其余开关置灰），**新建场景默认不启动**；场景表单里的提示词默认选中**当前生效的那份**（没有「不绑定」选项）。「提示词」页把这一份标成**「生效中」**并写明来源（`当前：life（场景「A」）`），**正在生效的那份不能删除**（按钮禁用 + 宿主拒绝），换绑或应用别的预设后即可删。「进入模式」会连同档案、记忆、提示词一起生效。
- **提示词预设**：新建弹窗改成「id + 正文文本框」（可直接把内容粘进去，也可从现有预设复制一份再改）；编辑时 **id 与正文都能改**——改 id 就是目录改名，**场景绑定会自动跟着改**，不留悬空绑定。id 不再限定小写字母/数字/连字符，**中文、空格、点、下划线都行**（只挡路径分隔符这类文件系统非法字符与 `__last-applied__` 备份槽）。
- **安全与界面**：插件 HTTP 路由接上宿主鉴权栅栏（Host/Origin 判定 + browser-session cookie；`token` 作为脚本与局域网部署的逃生门）；AGENTS.md 预设「应用」改为保留最近 **5 代**备份；全站 24 处弹窗的「取消 / 关闭」统一只在右上角；英文界面不再露中文（面板跟随宿主语言，会话页与 AGENTS.md 页接入词典）。

## v0.5.1（2026-09-13）

- **场景档案弹窗：新加的段默认一项都不勾**——MCP 工具集 / 技能集 / 子智能体绑定是**空集**，记忆段只预勾**本场景里已启用**的那几条；「全选」= 本场景全部。代价写进界面：空段 = 该域全部停用（子智能体段例外：空段 = 不限制）。
- **档案弹窗「记忆」段只列被编辑场景自己的记忆**：列别的场景（含「全局」）勾了不起作用，属于陷阱，已删除；记忆描述按 80 字截断，长描述不再横向溢出段边框。
- **场景页排版重做**：卡片只留「名字 + 标签 + 开关 / 一行描述 / 动作行」，数量收进页首「当前模式」条（只在真的进入模式后出现）；描述上限 60 字。
- **保留场景「全局」不再出现在场景页与档案弹窗**：它恒定注入、不是可切换的预设，MCP / 技能 / 人设各有专页；标签「任何对话都注入」压成「常驻」。
- 客户端契约测试补上「档案弹窗默认勾选」「记忆段只认本场景的记忆」「场景页不列全局」等用例；两份 README 的测试组清单同步校正。

## v0.5.0（2026-09-13）

- **破坏性：数据全部收进 `~/.dsh/tool-management/`**（记忆 / 人设 / AGENTS.md 预设 / 新建导入的技能 / 回收站 / 索引 / 配置）。旧位置首次启动**自动搬入**：只搬不删、绝不覆盖、每进程一次、失败不阻断（`~/.dsh/skills/` 不搬，仍作为可切换来源）。
- **场景从「恰好有这个名字的目录」升级为显式记录**（带描述与顺序）：空场景合法；保留场景「全局」恒在不可删；`memories/` 根层的裸 `.md` 不再注入并在体检里报 `noScene`。
- **技能来源**：新增插件自有来源 **「导入技能」**（新建 / 导入的落点，优先级高于 `~/.dsh/skills/`）；新增 **「移除来源」** = 连目录都不再扫描（源文件一个字节都不动，可一键恢复读取）。
- **界面**：工具页七栏；场景档案编辑器新增第 4 段「记忆」（只影响注入，不动记忆文件）；人设的模型与工具限制收进「高级选项」；四个表单的辅助提示去冗余。
- **修掉三个真故障**：工具页整页白屏、导出静默丢失（导出写在 `apply` 方法体内，`apply` 提前返回就没落地）、技能状态文件被判非法导致 Skills 页锁死。
- 斜杠命令 `/mcp`、`/skills`、`/agents-md`、`/scene-memory` 全部下线（面板里每一项都有等价入口）。

## v0.2.0 及更早（2026-09-12）

- 五个域合并进一个「工具」设置面板：**MCP / Skills / AGENTS.md 预设 / History（归档会话）**。
- **MCP**：工具级独立启停（模型看不见也调不到）、重启只重连**不改变启停状态**、密钥默认打码、改写补丁前自动 `.bak`（保留 5 份）、重复 loader id 写前拦截、跨级迁移失败自动回滚。
- **Skills**：接入 `~/.agents` / `~/.codex` / `~/.claude` 与自定义目录（只读接入、重叠拒绝）；创建 / ZIP 与文件夹导入 / 回收站；技能目录后台监听，编辑器改完自动刷新。
- **AGENTS.md 预设库**：多套全局基线，一键「应用」写入 `~/.dsh/AGENTS.md`（新会话生效，当前会话不变）。
- **History**：归档会话按项目分组、搜索、全选、批量恢复 / 永久删除、保留期自动清理；支持从 Claude Code / Cursor（JSONL）、Codex（Markdown）、任意文本导入；导出 Markdown / JSONL。
