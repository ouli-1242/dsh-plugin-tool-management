# ADR-1：规则（记忆）即文件

- 状态：已采纳（v0.2）
- 日期：2026-09-12

## 背景

需要一种既能让模型按需加载、又能让用户直接编辑的"规则/记忆"载体。可选形态有：单一 JSON 数据库、每规则一个文件、目录 bundle。

## 决策

**一条规则 = 一个 `.md` 文件**，平铺在 `$DSH_HOME/rules/<group>/<name>.md`。只有需要附件（模板、样例）时才使用目录 bundle（`<name>/SKILL.md` + 附件）。

## 理由

- `.md` 是 DSH 技能与 AGENTS.md 共用的既有格式，可被同一套 frontmatter 解析器读取（`src/skills/core.js` 的 frontmatter 解析）。
- 平铺文件让用户能用任意编辑器直接增删改，无需工具即可维护。
- 与 Claude Code 的 `~/.claude/rules` 形态对齐，降低迁移成本。

## 后果

- 发现逻辑必须自己实现（复用只读来源的递归遍历），不能把 `rules/` 挂为"可写来源"（可写来源只扫一层，子目录分组会失效）。
- 元数据（排序/标签/开关）放侧车 `rules-index.json`，不污染用户规则文件。
