# 文档导航

> 最后更新：2026-09-13 ｜ 本文件是 docs/ 的唯一索引门面，新增文档请同步登记。

## 目录结构

```text
docs/
├── 文档导航.md          ← 本文件（唯一索引门面 + 路径约定声明）
├── 决策记录.md          ← D-001~D-NNN 累积决策（六段式，单文件）（未建）
├── 技术依据.md          ← 官方来源/待确认标准 + 术语表（未建）
├── 规范.md              ← 编码标准（code-review Standards 轴第一来源）（未建）
├── 运行.md              ← runbook：环境/跑起来/测试/部署/排障（未建）
├── 测试.md              ← 项目级测试策略（未建）
├── 调研/                ← 可行性快验/Spike 产物
├── 设计/                ← 冻结的模块契约/spec
├── 计划/                ← 实施计划
├── 日志/                ← 按日开发记录
├── 审查/                ← 代码审查报告
├── 交接/                ← 阶段末交接与剩余任务
└── 实验/                ← 经验数据/实验记录
```

## 命名约定

- 计划 / 设计 / 日志 / 审查 / 交接 / 实验：`YYYY-MM-DD-简短主题.md`（必须带主题，不要只写日期）。
- 同一天同一类合并为一份，内部分节维护，不拆多文件。
- Status 行 `**Status:** draft|approved|completed` 作为标题下第一行内容，保持可 grep。
